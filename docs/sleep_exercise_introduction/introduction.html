1. はじめに

1.1. 本書の目的

エンジニア、デザイナー、事務職など、1 日の大半を座ってモニターに向かう仕事は、体を動かす機会が少ない。仕事に集中すると何時間も同じ姿勢のまま過ごし、夜遅くまで画面を見続けることも珍しくない。こうした働き方は、睡眠不足、肩こりや腰痛、運動不足を招きやすく、長い目で見ると生活習慣病のリスクを高める。

本書は、座り仕事が中心の人が健康的に働き続けるために、睡眠・姿勢・運動の 3 つについて、仕組みと具体的な方法を解説する。仕組みを理解しておけば、示した方法をそのまま真似るだけでなく、自分の仕事や生活に合わせて選んだり調整したりできる。そのため、各章ではまず「なぜそうするのか」を説明し、次に実践の方法を示す。

1.3. 睡眠・姿勢・運動のつながり

睡眠・姿勢・運動は、互いに影響し合っている（図 1.1）。日中に体を動かすと夜に寝つきやすくなり、よく眠れれば翌日に体を動かす意欲がわく。姿勢を支える筋力や柔軟性は運動で保たれ、首や腰に痛みがなければ体を動かしやすく、夜もよく眠れる。そして、この 3 つがそろうと、日中の集中力や作業の効率が上がる。

逆に、どれか 1 つが崩れると、ほかにも悪い影響が及ぶ。夜更かしで睡眠が不足すると、日中は眠気でだるくなって体を動かさなくなり、運動不足で夜の寝つきがさらに悪くなる、という悪循環に陥りやすい。本書で 3 つをまとめて扱うのはこのためである。

1.4. 本書の構成と読み方

本書の構成は次のとおりである。

  • 座り仕事と身体の基礎知識では、座りすぎが体に与える影響、エネルギー消費、姿勢を支える体の仕組み、体内時計の基本を説明する。

  • 睡眠のしくみと睡眠を整える実践では、睡眠の仕組みと、よく眠るための具体的な方法を説明する。

  • 姿勢と作業環境では、よい座り姿勢と作業環境の整え方、目や手首の負担を減らす方法を説明する。

  • 座りすぎを防ぐでは、作業中にこまめに休止を入れ、体を動かす方法を説明する。

  • 運動習慣では、推奨される運動量と、有酸素運動・筋力トレーニングの始め方を説明する。

  • 習慣化の方法では、ここまでの内容を無理なく続けるための習慣化の方法を説明する。

  • 不調のサインと受診の目安では、医療機関を受診すべき症状の目安を示す。

興味のある章から読んでもよいが、第 2 章と第 3 章の基礎知識を先に読むと、後の章の説明が理解しやすい。

本書には、休憩を知らせるタイマー、身体活動量の計算、睡眠記録の集計を行う Python のサンプルコードを付けた。それぞれ座りすぎを防ぐ、運動習慣、習慣化の方法で使い方を説明し、ファイルはサンプルコードからダウンロードできる。

1.6. 医療情報に関する注意

注意

本書は健康づくりのための一般的な情報をまとめたものであり、医師による診断や治療の代わりにはならない。持病がある人、治療中の人、妊娠中の人、体に痛みや違和感がある人は、運動や生活習慣を大きく変える前に医師に相談してほしい。症状が続く場合や強い症状がある場合は、不調のサインと受診の目安を参考に医療機関を受診してほしい。
