付録 D 手取り概算スクリプト

この付録では、給与収入（年収）から社会保険料・所得税・住民税・手取り額を概算する Python のスクリプトを紹介する。本書の 第 2 章 税金と社会保険の全体像 と 第 13 章 扶養と「年収の壁」 のグラフも、このスクリプトを使って作成している。

スクリプトは次のリンクからダウンロードできる。

  • take_home_pay.py

計算の前提

このスクリプトは、仕組みを理解するための概算を目的としている。次の前提を置いているため、実際の金額とは異なる場合がある。

計算の前提

項目

前提

対象とする収入

2026 年中の給与収入だけがある会社員またはパートタイマー。賞与はなく、毎月同じ額の給与を受け取る

社会保険

協会けんぽと厚生年金保険に加入する。健康保険料率は全国平均の 9.9 %、介護保険料率は 1.62 %（40 歳以上 65 歳未満）、子ども・子育て支援金率は 0.23 %、厚生年金保険料率は 18.3 %、雇用保険料率（本人負担）は 0.5 %

標準報酬月額

等級表は使わず、月給をそのまま標準報酬月額とみなす（上限と下限は考慮する）

所得控除

基礎控除と社会保険料控除のみ（扶養親族はない）

所得税

2026 年分の制度で計算する（給与所得控除の最低保障額 74 万円、基礎控除最大 104 万円、復興特別所得税 2.1 %）

住民税

2026 年の所得に対して 2027 年度に課される額を計算する。均等割は森林環境税を含めて 5,000 円とし、非課税限度額は単身・1 級地の基準（合計所得金額 45 万円）を使う

扶養に入る場合

--no-social-insurance を指定すると、社会保険料を負担しないものとして計算する

使い方

Python 3.10 以上が必要である。標準ライブラリだけを使っているため、追加のパッケージは不要である。コマンドプロンプトやターミナルで、スクリプトを保存したフォルダに移動し、次のように実行する。

1python take_home_pay.py 5000000
2python take_home_pay.py 5000000 --age 45
3python take_home_pay.py 1200000 --no-social-insurance

1 行目は年収 500 万円（30 歳）の場合、2 行目は年収 500 万円で 45 歳（介護保険料を負担する）の場合、3 行目は年収 120 万円で家族の扶養に入っている場合の計算である。

1 行目を実行すると、次のように表示される。

ソースコード

take_home_pay.py

  2
  32026 年（令和 8 年）中の給与収入を想定し、次の前提で計算する。
  4
  5* 会社員（協会けんぽ・厚生年金に加入）で、給与以外の収入はない。
  6* 賞与はなく、毎月同じ額の給与を受け取る。
  7* 扶養親族はなく、所得控除は基礎控除と社会保険料控除のみとする。
  8* 健康保険料率は協会けんぽの全国平均（9.9 %）を使う。
  9* 住民税は、2026 年の所得に対して翌年度（令和 9 年度）に課される額を計算する。
 10* 標準報酬月額の等級表は使わず、月給をそのまま標準報酬月額とみなす（上限と下限は考慮する）。
 11
 12実際の金額は、都道府県ごとの保険料率、賞与の有無、各種控除などにより異なる。
 13結果はあくまで目安として利用すること。
 14
 15使い方::
 16
 17    python take_home_pay.py 5000000
 18    python take_home_pay.py 5000000 --age 45
 19    python take_home_pay.py 1200000 --no-social-insurance

 33@dataclass(frozen=True)
 34class Assumptions:
 35    """社会保険料の計算に使う料率と上限。料率は労使合計の値で持つ。"""
 36
 37    health_rate: float = 0.099  # 健康保険料率（協会けんぽ全国平均）
 38    care_rate: float = 0.0162  # 介護保険料率（40 歳以上 65 歳未満）
 39    child_support_rate: float = 0.0023  # 子ども・子育て支援金率
 40    pension_rate: float = 0.183  # 厚生年金保険料率
 41    employment_rate_employee: float = 0.005  # 雇用保険料率（労働者負担分、一般の事業）
 42    health_monthly_floor: int = 58_000  # 健康保険の標準報酬月額の下限
 43    health_monthly_cap: int = 1_390_000  # 健康保険の標準報酬月額の上限
 44    pension_monthly_floor: int = 88_000  # 厚生年金の標準報酬月額の下限
 45    pension_monthly_cap: int = 650_000  # 厚生年金の標準報酬月額の上限
 46
 47
 48# 所得税の速算表: (課税所得金額の上限, 税率, 控除額)
 49INCOME_TAX_TABLE: tuple[tuple[float, float, int], ...] = (
 50    (1_949_000, 0.05, 0),
 51    (3_299_000, 0.10, 97_500),
 52    (6_949_000, 0.20, 427_500),
 53    (8_999_000, 0.23, 636_000),
 54    (17_999_000, 0.33, 1_536_000),
 55    (39_999_000, 0.40, 2_796_000),
 56    (float("inf"), 0.45, 4_796_000),
 57)
 58
 59RECONSTRUCTION_TAX_RATE = 0.021  # 復興特別所得税（2026 年分）
 60RESIDENT_INCOME_LEVY_RATE = 0.10  # 住民税の所得割（標準税率）
 61RESIDENT_PER_CAPITA_LEVY = 5_000  # 住民税の均等割（森林環境税 1,000 円を含む）
 62RESIDENT_TAX_EXEMPTION_LIMIT = 450_000  # 住民税が非課税となる合計所得金額（単身・1 級地）

100def employee_share(monthly_wage: float, floor: int, cap: int, rate: float) -> int:
101    """標準報酬月額に料率を掛け、本人負担分（半額）の年額を返す。"""
102    standard = min(max(monthly_wage, floor), cap)
103    return round(standard * rate / 2) * 12
104
105
106def social_insurance(annual_salary: int, age: int, assumptions: Assumptions) -> dict[str, int]:
107    """本人が負担する社会保険料（年額）を項目ごとに返す。"""
108    monthly = annual_salary / 12
109    a = assumptions
110    health_floor, health_cap = a.health_monthly_floor, a.health_monthly_cap
111    care = employee_share(monthly, health_floor, health_cap, a.care_rate) if 40 <= age < 65 else 0
112    pension = 0
113    if age < 70:
114        pension = employee_share(monthly, a.pension_monthly_floor, a.pension_monthly_cap, a.pension_rate)
115    return {
116        "health": employee_share(monthly, health_floor, health_cap, a.health_rate),
117        "care": care,
118        "child_support": employee_share(monthly, health_floor, health_cap, a.child_support_rate),
119        "pension": pension,
120        "employment": round(annual_salary * a.employment_rate_employee),
121    }

129def salary_income_deduction(salary: int, minimum: int) -> int:
130    """給与所得控除額を返す。minimum は最低保障額。"""
131    if salary <= 1_900_000:
132        amount = 0.0
133    elif salary <= 3_600_000:
134        amount = salary * 0.3 + 80_000
135    elif salary <= 6_600_000:
136        amount = salary * 0.2 + 440_000
137    elif salary <= 8_500_000:
138        amount = salary * 0.1 + 1_100_000
139    else:
140        amount = 1_950_000
141    return min(salary, max(minimum, int(amount)))

144def basic_deduction_income_tax(total_income: int) -> int:
145    """所得税の基礎控除額（令和 8 年分）を返す。"""
146    if total_income <= 4_890_000:
147        return 1_040_000  # 本則 62 万円 + 特例 42 万円
148    if total_income <= 6_550_000:
149        return 670_000  # 本則 62 万円 + 特例 5 万円
150    if total_income <= 23_500_000:
151        return 620_000
152    if total_income <= 24_000_000:
153        return 480_000
154    if total_income <= 24_500_000:
155        return 320_000
156    if total_income <= 25_000_000:
157        return 160_000
158    return 0
159
160
161def progressive_income_tax(taxable: int) -> int:
162    """速算表を使って課税所得金額から所得税額（復興特別所得税を除く）を返す。"""
163    for upper, rate, subtract in INCOME_TAX_TABLE:
164        if taxable <= upper:
165            return max(0, int(taxable * rate) - subtract)
166    raise ValueError("課税所得金額が速算表の範囲外である。")
167
168
169def income_tax(annual_salary: int, social_insurance_total: int) -> int:
170    """所得税と復興特別所得税の合計額を返す。"""
171    # 令和 8 年分の給与所得控除の最低保障額は 74 万円（本則 69 万円 + 特例 5 万円）
172    total_income = annual_salary - salary_income_deduction(annual_salary, 740_000)
173    deductions = basic_deduction_income_tax(total_income) + social_insurance_total
174    taxable = max(0, total_income - deductions) // 1_000 * 1_000
175    total = int(progressive_income_tax(taxable) * (1 + RECONSTRUCTION_TAX_RATE))
176    return total // 100 * 100

184def basic_deduction_resident_tax(total_income: int) -> int:
185    """住民税の基礎控除額を返す。"""
186    if total_income <= 24_000_000:
187        return 430_000
188    if total_income <= 24_500_000:
189        return 290_000
190    if total_income <= 25_000_000:
191        return 150_000
192    return 0
193
194
195def adjustment_deduction(taxable: int, total_income: int) -> int:
196    """調整控除額（扶養親族がない場合）を返す。"""
197    if total_income > 25_000_000:
198        return 0
199    gap = 50_000  # 基礎控除の所得税と住民税の差
200    if taxable <= 2_000_000:
201        return int(min(gap, taxable) * 0.05)
202    return max(2_500, int((gap - (taxable - 2_000_000)) * 0.05))
203
204
205def resident_tax(annual_salary: int, social_insurance_total: int) -> int:
206    """住民税（所得割と均等割）の合計額を返す。"""
207    # 令和 9 年度分の住民税の給与所得控除の最低保障額は 74 万円
208    total_income = annual_salary - salary_income_deduction(annual_salary, 740_000)
209    if total_income <= RESIDENT_TAX_EXEMPTION_LIMIT:
210        return 0
211    deductions = basic_deduction_resident_tax(total_income) + social_insurance_total
212    taxable = max(0, total_income - deductions) // 1_000 * 1_000
213    levy = int(taxable * RESIDENT_INCOME_LEVY_RATE) - adjustment_deduction(taxable, total_income)
214    levy = max(0, levy) // 100 * 100
215    return levy + RESIDENT_PER_CAPITA_LEVY

223def calculate(annual_salary: int, age: int = 30, enrolled: bool = True,
224              assumptions: Assumptions | None = None) -> Result:
225    """年収から社会保険料・税金・手取り額を計算する。
226
227    enrolled が False の場合は、家族の扶養に入っていて社会保険料を負担しないものとして計算する。
228    """
229    if annual_salary < 0:
230        raise ValueError("年収には 0 以上の値を指定すること。")
231    if enrolled:
232        insurance = social_insurance(annual_salary, age, assumptions or Assumptions())
233    else:
234        insurance = {"health": 0, "care": 0, "child_support": 0, "pension": 0, "employment": 0}
235    insurance_total = sum(insurance.values())
236    return Result(
237        annual_salary=annual_salary,
238        health_insurance=insurance["health"],
239        care_insurance=insurance["care"],
240        child_support=insurance["child_support"],
241        pension=insurance["pension"],
242        employment_insurance=insurance["employment"],
243        income_tax=income_tax(annual_salary, insurance_total),
244        resident_tax=resident_tax(annual_salary, insurance_total),
245    )
246

248def display_width(text: str) -> int:
249    """全角文字を幅 2 として文字列の表示幅を返す。"""
250    return sum(2 if unicodedata.east_asian_width(c) in "WF" else 1 for c in text)
251
252
253def format_row(label: str, amount: int) -> str:
254    """ラベルと金額を桁をそろえて 1 行にする。"""
255    padding = " " * (24 - display_width(label))
256    return f"{label}{padding}{amount:>12,} 円"
257
258
259def report(result: Result) -> str:
260    """計算結果を表示用の文字列にする。"""
261    rate = result.take_home / result.annual_salary * 100 if result.annual_salary else 0.0
262    lines = [
263        format_row("年収（給与収入）", result.annual_salary),
264        "",
265        format_row("  健康保険料", result.health_insurance),
266        format_row("  介護保険料", result.care_insurance),
267        format_row("  子ども・子育て支援金", result.child_support),
268        format_row("  厚生年金保険料", result.pension),
269        format_row("  雇用保険料", result.employment_insurance),
270        format_row("社会保険料の合計", result.social_insurance_total),
271        "",
272        format_row("  所得税（復興税を含む）", result.income_tax),
273        format_row("  住民税", result.resident_tax),
274        format_row("税金の合計", result.tax_total),
275        "",
276        format_row("手取り（概算）", result.take_home) + f"（年収の {rate:.1f} %）",
277    ]
278    return "\n".join(lines)

281def main() -> None:
282    """コマンドライン引数を読み取り、計算結果を表示する。"""
283    parser = argparse.ArgumentParser(description="年収から手取り額を概算する（2026 年の収入を想定）。")
284    parser.add_argument("salary", type=int, help="年収（給与収入、円）")
285    parser.add_argument("--age", type=int, default=30, help="年齢（介護保険料の判定に使う。既定値は 30）")
286    parser.add_argument("--no-social-insurance", action="store_true",
287                        help="社会保険料を負担しない（家族の扶養に入っている）ものとして計算する")
288    args = parser.parse_args()
289    result = calculate(args.salary, age=args.age, enrolled=not args.no_social_insurance)
290    print(report(result))
